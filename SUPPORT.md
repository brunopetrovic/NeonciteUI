# Support

Neoncite/UI is currently an actively developed pre-1.0 open-source project.

For reproducible bugs, use GitHub Issues and include the component or CLI command involved, your React/Tailwind versions, reproduction steps, and relevant error output.

For feature or component requests, explain the production use case rather than only requesting visual parity with another library. Neoncite prioritizes reusable primitives and technical-product interfaces that fit its design system.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not publish undisclosed vulnerability details in a public issue.

No paid support SLA, private support channel, or guaranteed response time is currently advertised by this repository.
