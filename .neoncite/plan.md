# Neoncite UI Architecture Plan

## Overview
Neoncite UI is an opinionated, dark-mode-first React component library featuring deep OLED black surfaces, hardware rim lighting, and a 9-color neon palette built on Radix UI and Tailwind CSS v4.

## Core Pillars
1. **OLED Surface Hierarchy:** `#050507` canvas, `#0c0d12` recessed, `#12131a` elevated machined card.
2. **Hardware Rim Lighting:** Dual top bevel glow + hairline borders.
3. **Copy-Paste Registry:** Shadcn-compatible JSON registry + CLI (`npx neoncite`).
4. **Clean Dark Theme:** Strictly dark-mode-first aesthetic with precision neon accents.
